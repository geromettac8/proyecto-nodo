
# NODO Estudio Digital 💙

Sitio web desarrollado como proyecto del curso de Desarrollo Web de Coderhouse.

## Sobre el proyecto

NODO Estudio Digital es un estudio enfocado en estrategias de publicidad digital para marcas y emprendimientos.

El sitio presenta nuestros servicios, proyectos y canales de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Bootstrap 5
- Git y GitHub

## Secciones del sitio

- Inicio
- Sobre NODO
- Servicios
- Proyectos
- Contacto
